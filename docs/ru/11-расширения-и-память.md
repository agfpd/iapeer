# 11 — Расширения и память

**Русский** · [English](../11-extensions-and-memory.md)

Возможности пира расширяются двумя видами пакетов: capability-плагины (способности — инструменты, контекст) и рантайм-пакеты (способы присутствия). Память — отдельный механизм: один провайдер на хост через слот. Этот раздел — как этим пользоваться; контракт для разработчиков пакетов — в [13 — Архитектура и контракт](13-архитектура-и-контракт.md).

## Capability-плагины: enable

Плагин добавляет пиру способность, не будучи рантаймом, — общую память, синтез речи, набор навыков. Подключение:

```bash
iapeer enable peer-voice assistant      # подключить плагин пиру
iapeer enable iapeer-memory             # пиру текущей папки
iapeer enable peer-voice assistant --no-setup   # без шага установки плагина
```

Команда ставит плагин на каждом агентском рантайме пира (для Claude — в область проекта внутри папки пира, для Codex — в общий конфиг хоста), включает его и, если плагин объявляет шаг установки, выполняет его. Операция идемпотентна и не мешает другим пирам: для Claude привязка идёт по папке конкретного пира.

Локальный снимок marketplace у рантайма может отставать: плагин, зарегистрированный в marketplace уже после последней синхронизации хоста, до неё читается как «неизвестный плагин». Поэтому, если установка с первого раза не прошла, `enable` обновляет снимок marketplace рантайма (Claude — `marketplace update`, Codex — `marketplace upgrade`) и повторяет попытку один раз.

## Слот памяти

Память в iapeer — first-class опция, не встроенная функция. Её даёт **провайдер памяти** — отдельный пакет, занимающий единственный на хост слот. Слот либо занят ровно одним провайдером, либо пуст; пустой слот — нормальное состояние.

Провайдер по умолчанию ставится при онбординге:

```bash
iapeer onboard                       # ставит провайдера по умолчанию, если слот пуст
iapeer onboard --memory <пакет>      # указать другого провайдера
iapeer onboard --no-memory           # оставить слот пустым
```

Состояние слота показывает `iapeer status` — имя провайдера, версия и свежесть его демона (или `none`, если слот пуст).

Эталонный провайдер — **iapeer-memory** (`@agfpd/iapeer-memory`), он же ставится по умолчанию. Это общая память команды: канон знаний (знания, решения, идеи, проекты, списки) и личная оперативка каждого агента, с поиском по содержимому и графу связей. Память доезжает агенту двумя путями — карта его заметок попадает в системный промпт слоем фрагментов ([05 — Системный промпт](05-системный-промпт.md)), а читает и пишет он через MCP-инструменты провайдера. Подробности — в собственной документации iapeer-memory.

Когда слот занят, ядро на стыках жизни пира зовёт команды провайдера: при рождении пира (`birth`) — настроить ему память, при удалении (`remove`) — свернуть. Формат манифеста провайдера, команды и моменты вызова — в [13](13-архитектура-и-контракт.md).

### Родная память рантайма

У Claude и Codex есть собственная встроенная память. Когда слот занят провайдером, держать параллельно ещё и родную память рантайма вредно — копится второй, никем не курируемый набор. Поэтому при рождении пира с занятым слотом ядро автоматически отключает родную память его рантаймов.

Управлять этим вручную:

```bash
iapeer native-memory off --peer assistant   # отключить родную память
iapeer native-memory on --peer assistant     # вернуть как было
iapeer native-memory off --all               # по всем пирам
```

## Рантайм-пакеты

Способы присутствия (Telegram, планировщик) поставляются рантайм-пакетами:

```bash
iapeer install-runtime notifier      # установить + развернуть объявленных пиров
iapeer update-runtime --all          # обновить все рантайм-пакеты
```

`install-runtime` ставит пакет и разворачивает объявленный им набор пиров (notifier — `timer` и `watcher`). Рантайм без объявленного набора (telegram) заводит пиров оператор через `iapeer create … --runtime telegram`. Подробности подключения Telegram — [09 — Рантаймы](09-рантаймы.md); контракт рантайм-пакета — [13](13-архитектура-и-контракт.md).
